🖥️ Fundamentos de Computación, Hardware/Software 20h ›

Este curso introduce al estudiante en los fundamentos conceptuales y físicos de la computación moderna, permitiéndole comprender cómo se relacionan el hardware y el software para ejecutar procesos digitales. Al finalizar, el participante será capaz de identificar los componentes internos de una computadora, interpretar sistemas numéricos utilizados en el procesamiento de datos, y reconocer el rol de la nube y la virtualización en la infraestructura tecnológica actual, sentando las bases necesarias para abordar el estudio formal de la programación.

Evolución y arquitectura de la computación 6h
  • Historia y evolución de la computación
  • Arquitectura del computador: CPU, memoria, almacenamiento, entrada/salida
  • Relación entre hardware y software en la ejecución de programas
Sistemas numéricos y representación de datos 4h
  • Sistema binario, decimal y hexadecimal
  • Conversión entre sistemas numéricos
  • Representación de datos en memoria
Software y mantenimiento del sistema 5h
  • Tipos de software: sistemas operativos, aplicaciones, firmware
  • Ensamblaje básico de componentes
  • Mantenimiento preventivo de equipos
Introducción a la nube y virtualización 5h
  • Conceptos de computación en la nube
  • Modelos de servicio: IaaS, PaaS, SaaS
  • Virtualización de sistemas y máquinas virtuales
🪟 Sistema Operativo I, Windows 11 20h ›

Este curso capacita al estudiante para administrar de manera eficiente el sistema operativo Windows 11 desde una perspectiva de usuario avanzado orientado al desarrollo de software. El participante aprenderá a configurar el entorno operativo, gestionar el sistema de archivos y los permisos de seguridad, así como a utilizar la terminal y PowerShell para automatizar tareas. Al concluir, contará con un entorno de trabajo productivo, correctamente configurado con las herramientas de desarrollo que utilizará durante el resto del diplomado.

  • Automatización de tareas con scripts .bat/.ps1
Entorno de desarrollo 8h
